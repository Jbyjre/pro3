> Current Breathe behavior: [app-open breathing](../../../../../../../../docs/APP_OPEN_BREATHING.md). A dedicated event-driven service covers the first open of each selected ordinary app for a short pause (3 seconds by default, customizable), without screen-content retrieval.

# Verification

Run the repository's testFossDebugUnitTest, lintFossRelease and signed assembleFossRelease tasks. Cloud setup supplies the dependency cache, Android SDK/NDK and Robolectric image; a full JDK 21 is required. Tests render/run on Robolectric API 36, compiling/targeting API 37. This is neither a physical Samsung nor a claim of emulator radio/compositor testing.

- BreathSessionTest and BreathLaunchTest check actual first-draw/handler launch order at 2,999/3,000 ms, one completion, cancellation, old disabled/snoozed preference immunity, duplicates, lock and process restore. Legacy shortcuts never stack another service pause.
- BreathAccessServiceTest exercises the actual service/window manager: immediate attachment on a prepared activity event, exact deadline, no launcher-intent replacement, repeated events, dialogs/keyboards, Home/app switches, screen off, shade reentry, Back, selection removal and disconnect cleanup. Injected attachment failure, first-frame timeout and interruption during a newly installed activity lookup verify recovery without delayed popups. Selection changes are checked before metadata loading finishes, and display-off events must wait for an interactive display. BreathAppGateTest checks transitions and shortcut exemption consumption/expiry.
- BreathSetupTest drives actual Settings access, separately verifies enabled/connected states, revokes on resume and renders normal/large-text layouts. It also captures the needs-attention recovery state. BreathingUiTest checks persisted appearance, real app-name search, whole-row selection and the chosen-app filter at enlarged text, including search and selection in a 320×480 dp viewport.
- BreatheDesignTest checks actionable setup status, expandable connection/privacy help, the real App info route, clear-search/Done persistence, finite preview playback, background cancellation, no resume restart, live reduced-motion changes, and dark-theme palette/motion controls. Native light/dark/picker/large-text captures are under screenshots/breathe.
- BreathAppGateTest, BreathTimelineTest, BreathWordsTest, BreathRulesTest, BreathGrayTest, InstallFailureTest and BreathWebAppsTest are pure-logic checks: the pause rule (switching back, closing and reopening, a peek at Recents, notifications, modes, break time, retry, wake), the seven exits' timeline math, the verse and your own words, per-app rules, grayscale detection, install-failure explanations, and the Chrome web-app rules.
- BreathAccessServiceTest also covers system windows never cutting a pause short, the grace time across apps and service restarts, Chrome web-app windows with Chrome chosen, custom length and transition, rotating sayings and recorded timing. BreathScreenshots adds flicker guards (opaque first frame in every palette, a fade that never rises, lift reveals bottom-up, instant stays solid).
- UpdateFlowTest covers the check-on-open throttle (6 hours, clock moved back, offline retry, checks off, unmetered download rule).
- BreathScreenshots records native production-view transition frames. AppTourScreenshots covers Breathe, Phone and retained headphone screens. Images do not prove smoothness/frame rate.
- UpdatePolicyTest and UpdateFlowTest use controlled newer/invalid/missing/rate-limited/offline/republished releases, verify channel/version/signature policy, interrupted download cleanup and retry controls, expired installer sessions, retained retries, pending confirmation and callback session ownership.
- OverlayLayerTest / IslandHandoverTest retain popup permission/removal/touch cleanup and below-status-bar placement. PopupGate checks duplicates without extending display. Camera-only renderer/rule/editor/screen-reader tests are retired with those deleted features; mixed popup, artwork, heart, timer, battery and headphone coverage stays.
- Existing AirPodsProtocolTest, AirPodsUiFixesTest, PhoneTabsUiTest, BatteryAuditTest (including close-range unverified BLE fallback and AACP listener preservation across reconnects), SmartAudioRulesTest (voice-typing/unrooted ownership protection, battery-packet connect/disconnect rules, case wakeup, Conversation Awareness suppression during voice typing, 15-minute auto-resume expiry, and unexpected disconnect alerts), PowerPlan tests and headphone/heart tests remain regression evidence. Headphones remain Home and Breathe replaces Island.
- NowPlayingTest checks buffering-session selection, cover-art isolation when two apps publish the same song, and live metadata updates. Retired sound-attribution tests remain removed.

Actual Samsung checks are in the root TESTING.md. Record observed totals/results in docs/BREATHING_AND_UPDATES.md after running, never assume green from compilation or snapshots.
