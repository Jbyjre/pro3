# Check app-open breathing on the phone — 16 November

1. Install the new **correctly signed** build over pro; keep existing data. Open Breathe. Choose an ordinary app, tap Connect Breathe and enable **pro · Breathe** in Android Accessibility. If restricted, use the App info link and Android's Allow restricted settings. Return: it must say **Ready when you open** only when Android has enabled and connected the service. No shortcut, Bluetooth, overlay permission, usage access or notification access is needed for breathing.
2. In Choose apps, tap the app name or anywhere on its row, then use Chosen to review the list. Try large text, long app names, search within Chosen and deselection. Return to Breathe and confirm the count updates.
3. Open a selected app with its **original icon**, then via a notification, a web/deep link from another app and Recents. Measure event/open-to-first-layer separately from the **2.5 seconds from the first breathing frame**. Record a screen video; the Android event can arrive after the destination's first frame, so cloud tests cannot certify zero exposure or subsecond Samsung latency. Logcat tag `Breathe` records attach-to-first-draw time without package names or screen content.
4. Confirm the exact conversation/article opened by a notification/link remains after the pause; no launch of the app's home activity. Try app-internal activity switches, dialogs, keyboards, rapid A→B→A and Home→same-app reentry. One layer only; duplicate events never extend it.
5. During the pause use Home, Back (button and gesture), lock, notification shade and incoming calls. No stuck touch target, delayed app launch or replay. Try rotation, split screen and display-size changes. Accessibility window ordering and gestures require real-device validation.
6. Try Cobalt/Tangerine/Pool, Still mode, system animation scales 0×/1×/10× and 1.8× text. Preview and live layer should match; duration stays 2.5 seconds. Breathe has no off/pause/tile control. Old disabled/snoozed preferences must not bypass it. Removing an app from the chosen list removes coverage for that app.
7. Close pro's task, restart the phone, revoke/regrant access, force-stop and reopen pro, then upgrade. Confirm selections survive and connection status is accurate. Android can stop/revoke access; the app must never claim connected when it isn't. A force-stop is not something pro can bypass. If the page reports “Breathe needs attention,” open a chosen app again or use Check connection. Verify successful retry clears that state; it must not be confused with missing Accessibility access.
8. Recheck AirPods/Beats listening controls, music, heart readings and temporary pop-ups. Routine headphone events should not cover or extend the breath. Keep original app identity/signature and existing update flow. Follow the updater and headphone checks in [the previous checklist](docs/BREATHING_AND_UPDATES.md).

Cloud unit/integration/render tests are recorded in [the delivery notes](docs/APP_OPEN_BREATHING.md). They do not measure a physical Galaxy's event delivery, compositor timing, gesture behavior, background retention or Bluetooth.

## Retained headphone and updater checks

1. **Pop-ups and headphones.** Connect AirPods and Beats, play/pause/skip music, change listening mode, remove/reinsert a bud, and check low-battery behavior when possible. Useful controls should still work. Repeat connection broadcasts/reconnects must not keep extending a pop-up. It should dismiss on lock/rotation and leave no touch target. Routine connection/music events during breathing should be dropped, never lengthen it. System shade, calls and installer confirmation remain usable.
2. **Permissions.** In Phone, open each missing access control, grant it in Android Settings, and return: the prompt must disappear or the Update button must change from Allow pro updates to Update. Revoke each access and return: recovery controls must reappear. Test notification denial and its Notification settings link; if music access is restricted, use pro’s App info to allow restricted settings before retrying. Breathing must continue working without these accesses.
3. **Update once.** Phone > App updates > Check now. Confirm the real installed build number and chosen channel. Download a newer build and tap Update. Allow pro to install apps once if Android asks. A required system confirmation should open automatically for the foreground action; approve it. Settings and enabled features should survive, then open pro once if Android/OEM recovery did not resume headphones. Test denied install permission, cancelled confirmation, offline checks, and retry. Samsung Auto Blocker may require an explicit security choice; pro cannot bypass it. Never uninstall as the normal update path.
4. **Optional idle installation.** Enable it only if wanted, finish important recording sessions, then let the phone idle on Wi-Fi without music/calls. Observe whether Android silently updates or posts confirmation. Report which occurred; this has not been verified on a physical Samsung. Stable cannot downgrade a higher preview version. No repeated nagging should occur from cancelled/blocked updates.

For a freeze/crash, open Settings > Troubleshooting > Freezes and crashes and copy details. Never share the private signing backup in an issue or public message.
