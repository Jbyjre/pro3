# Check this update on the Galaxy S26 FE

Current design and verified scope: [Breathing and updates](docs/BREATHING_AND_UPDATES.md). Old camera-island checklists are superseded. Cloud checks do not verify One UI 9 timing, Bluetooth hardware or silent installation.

1. **Upgrade without losing data.** Install the new signed pro APK over the existing installation, then open it once. Confirm saved device, listening controls, heart settings and paired headphones remain. Headphones is still the first/default tab. Nothing should remain around the camera, even with music, no headphones, or the former Off mode. Tap/drag across the camera area to confirm no old window intercepts touches. The old Accessibility entry should be gone.
2. **Set up one app.** Breathe > Choose apps & add shortcuts. Search the real installed app (Chess, Claude, Meta Muse, ChatGPT, ESPN, ESPN Fantasy are examples, not hard-coded packages). Select one, Add icon, accept the launcher prompt, then use that added home-screen icon. The original icon/app drawer, Recents, notifications and deep links deliberately open directly. No launcher replacement, Bluetooth reconnection or accessibility permission should be requested.
3. **Launch and time.** Try the breathing icon after closing pro, with pro warm, with the target cold, and with an existing target session. Record a screen video if possible: measure from first breathing frame to destination launch separately from OS splash/startup time. There must be one color layer sweeping upward and no Continue/second delay. Confirm the target has not appeared or accepted touches before the pause. Do not treat an observed late overlay as success. Test animator speed Off / 1× / 10× and reduced motion; the intervention should still be one second. Actual frame smoothness is a phone check.
4. **Cancel and resize.** During the pause try Home, Back, lock, notification shade and an incoming call. No later surprise launch. Try rapid repeated shortcut taps, different selected shortcuts, target dialogs/keyboard, rotation, landscape and split screen; no loop or repeat from target activities. Reopen pro after system stop/restart; selections remain. Uninstall a selected target: its stale shortcut must fail safely. Disabling breathing should let selected shortcuts open directly. Test optional 15-minute pause and Quick Settings toggle. Pick Cobalt, Tangerine and Pool and Still mode, leave/reopen pro, then launch the shortcut: the saved choice must match the preview (previous Electric/Coral/Lagoon choices become Cobalt/Tangerine/Pool) and still last one second. Use large text to confirm color choices wrap and remain tappable.
5. **Pop-ups and headphones.** Connect AirPods and Beats, play/pause/skip music, change listening mode, remove/reinsert a bud, and check low-battery behavior when possible. Useful controls should still work. Repeat connection broadcasts/reconnects must not keep extending a pop-up. It should dismiss on lock/rotation and leave no touch target. Routine connection/music events during breathing should be dropped, never lengthen it. System shade, calls and installer confirmation remain usable.
6. **Permissions.** In Phone, open each missing access control, grant it in Android Settings, and return: the prompt must disappear or the Update button must change from Allow pro updates to Update. Revoke each access and return: recovery controls must reappear. Test notification denial and its Notification settings link; if music access is restricted, use pro’s App info to allow restricted settings before retrying. Breathing must continue working without these accesses.
7. **Update once.** Phone > App updates > Check now. Confirm the real installed build number and chosen channel. Download a newer build and tap Update. Allow pro to install apps once if Android asks. A required system confirmation should open automatically for the foreground action; approve it. Settings and enabled features should survive, then open pro once if Android/OEM recovery did not resume headphones. Test denied install permission, cancelled confirmation, offline checks, and retry. Samsung Auto Blocker may require an explicit security choice; pro cannot bypass it. Never uninstall as the normal update path.
7. **Optional idle installation.** Enable it only if wanted, finish important recording sessions, then let the phone idle on Wi-Fi without music/calls. Observe whether Android silently updates or posts confirmation. Report which occurred; this has not been verified on a physical Samsung. Stable cannot downgrade a higher preview version. No repeated nagging should occur from cancelled/blocked updates.

For a freeze/crash, open Settings > Troubleshooting > Freezes and crashes and copy details. Never share the private signing backup in an issue or public message.
